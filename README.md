# Informe y propuesta — EscortPorMadrid

Documento para el cliente: auditoría del sitio actual con las 22 fallas clasificadas por
gravedad, comparativa antes/después medida, alcance del sitio nuevo y plan de ejecución.

> **No es el sitio en producción.** Es un documento de propuesta comercial.

- `index.html` — el informe y la propuesta.
- `demo.html` — la propuesta visual, navegable (8 perfiles ficticios, marcadores de posición).

Demo: https://advfalcorreia-commits.github.io/sanbenitoescorts/

## Qué contiene el informe

1. Resumen en tres grupos: riesgo legal, pérdida de dinero, deuda técnica.
2. Las 5 fallas críticas, con evidencia y coste de cada una.
3. Las 9 fallas altas.
4. Las 8 fallas medias.
5. Comparativa antes/después, medida el 05/11/2026.
6. Qué incluye el sitio nuevo (agente WhatsApp + Telegram 24 h, identidad visual,
   mayoría de edad y consentimiento dentro de la base de datos).
7. Plan de ejecución por semanas.
8. Enlace a la propuesta visual.

## Notas

- Todo el contenido está en un único HTML por página, sin dependencias salvo las fuentes.
- Está preparado para imprimir a PDF: `Ctrl/Cmd + P` produce un documento limpio, sin la
  barra de navegación.
- No indexado (`noindex, nofollow`): es una propuesta, no debe competir con el sitio real
  del cliente en Google.
- Los números de peso y peticiones se midieron con compresión activa en ambos sitios. El
  tiempo de respuesta no se compara: el sitio nuevo se midió en servidor local.
